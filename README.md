# TopCars Co. Ltd - Salesperson Analysis Dashboard

## Overview
Power BI dashboard analyzing salesperson performance including commission calculation, order distribution, and multi-dimensional drill-down analysis.

## Features
- Salesperson filter slicer
- Commission calculation (5% for price >= 30,000, else 3%)
- Clustered bar chart: Total commission by salesperson
- Donut chart: Total orders by salesperson
- Decomposition tree: Orders by salesperson, month, manufacture, model, vehicle type
- KPI cards: Total commission & highest paid commission

## Tools Used
- Microsoft Power BI
- DAX (calculated columns & measures)
